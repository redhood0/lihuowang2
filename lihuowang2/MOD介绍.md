# 李火旺 —— 杀戮尖塔2 角色 Mod

> 这是塔1，还是塔2，我分不清……

## 简介

这是一个《杀戮尖塔 2》的角色 Mod，把《道诡异仙》的主角**李火旺**请进了尖塔。

他带着满身伤和满脑子疑问往上爬：分不清现实与幻觉，分不清自己是在爬塔还是在犯病，也分不清眼前这些怪物究竟是真的邪祟，还是自己的又一个梦。

- **新角色：李火旺**，初始 **80 生命**、**0 金币**，拥有独立的卡池、遗物池与药水池。
- **70 余张卡牌、16 件遗物、17 种状态、3 个专属事件**，以及专属关键词「**预见**」。
- 配套角色选择背景、能量表盘、商店与火堆场景，卡框采用偏鲜红的配色。
- 中英双语本地化；本 Mod 的特殊 BGM 可在「模组设置」中单独开关。

## 角色特色

李火旺的强度从来不靠稳扎稳打，而是靠**代价**换来的。

| 流派 | 玩法关键词 |
|---|---|
| **疯癫** | 进入疯癫后伤害 +50%、受伤 -25%，但疯癫时部分「清明」招式打不出去——要么发癫，要么清醒。 |
| **大千录** | 断指、剜眼、拔牙、剥皮……用自身生命换取远超常规的收益，再用回复把血线拉回来。 |
| **诅咒** | 主动往牌组里塞「疑虑」「悔恨」「扭曲」，用魍魉之躯把诅咒喂成力量，或用黑太岁消化它们换抽牌与格挡。 |
| **离火 / 点燃** | 用「灼烧」堆叠点燃，玩火自焚、火中取栗，最后一把火烧尽全场；火袄真经则让灼烧变成回血手段。 |
| **煞气** | 越战越猛，攻击额外附带煞气层数伤害；但 5 层以上你将无法再获得格挡，每回合只给全场挂易伤。 |
| **铜钱** | 撒币攻击、收钱格挡，钱越多打得越狠；攒下的铜钱还能换成金币。 |
| **丹药 / 丹炉** | 每回合白嫖一张随机丹药；但服下「丹阳子化」之后，每回合都会被师父抢走能量。 |

此外还有 **李岁** 的两条支线（狗形态 / 公主形态）与「黑太岁」触手体系，以及「苍蜣登阶」这条越痛越强的极端路线。

## 内容一览

- **卡牌**：70 余张，覆盖攻击、技能、能力、状态与诅咒，含初始打击 / 防御、大千录系列、触手系列、铜钱剑系列与李岁系列。
- **遗物**：16 件，如心素、登阶计数、黑手、火袄真经、替身人皮、铜钱剑、骗经、玄天八卦镜等。
- **状态**：17 种，如疯癫、黑太岁、点燃、煞气、丹炉、怜悯、魍魉之躯、丹阳子化、天书等。
- **事件**：3 个专属事件——「第二附属医院」「深山洞府」「祆景教洞府」。
- **关键词**：预见（查看抽牌堆顶若干张牌，并可丢弃其中任意张）。
- **BGM**：坐忘道、登阶、离火、成仙等专属曲目，会在特定卡牌打出、进商店与通关时切歌。

## 安装与依赖

1. 先把 Mod 目录放进游戏的 `mods` 文件夹。
2. 需要的依赖：
   - `STS2-RitsuLib`（本 Mod 基于其内容注册与角色脚手架构建）
   - `MinionLib`
3. 游戏版本最低要求：STS2 `0.111.0`。

如果不想听 Mod 的特殊 BGM，进「模组设置 → 李火旺模组 → 音乐」把「播放特殊 BGM」关掉即可，游戏原声不受影响。
